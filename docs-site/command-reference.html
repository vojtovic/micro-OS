Command Reference

Current shell command set registered in firmware.

Core shell commands

CommandDescription
helpList available commands.
rebootRestart the board immediately.
memShow internal RAM and PSRAM totals/free.
mountMount SD card at /sdcard.
unmountUnmount SD card.
cd [path]Change working directory (defaults to /sdcard). Supports . and .. path normalization.
pwdPrint current working directory.
ls [path]List directory contents.
cat <file>Print file content.
historyShow recent command history.

File and script commands

CommandDescription
write <file> <text...>Overwrite file with text + newline.
append <file> <text...>Append text + newline to file.
mkdir <path>Create directory.
rmdir <path>Remove empty directory.
rm <file>Remove file.
touch <file>Create empty file if missing.
stat <path>Show type and size.
dfShow /sdcard and /sys capacity/usage.
cp <src> <dst>Copy file.
mv <src> <dst>Rename/move file.
head [-n N] <file>Show first lines.
tail [-n N] <file>Show last lines (up to 32-line buffer).
grep <pattern> <file>Substring search with line numbers.
wc <file>Print line/word/byte counts.
hexdump <file> [offset] [length]Hex and ASCII view.
tree [path]Recursive directory listing (depth-limited).
note [text...]Append timestamped note to /sys/log/notes.log or print notes.
source <script>Execute command script line-by-line.
find <pattern> [path]Recursive name search.
du [path]Recursive size summary.
basename <path>Path tail helper.
dirname <path>Path parent helper.
test <-f|-d|-e|-s> <path>Existence/type checks by exit code.

System commands

CommandDescription
unameOS/chip/IDF summary string.
uptimeTime since boot.
dateRTC placeholder status.
psFreeRTOS task list.
clearClear terminal screen.
echo <text...>Print text.
hostnamePrint hostname (micro_arch).
envPrint environment-like board info.
freeMemory table (IRAM/PSRAM).
lscpuCPU architecture/features summary.
shutdownUnmount filesystems then restart.
lsblkShow flash partitions and SD status.
which <cmd>Search in /sdcard/bin and /sdcard/drivers.
modload <path.elf>Load module ELF into runtime (does not start it).
modstart <name>Start a loaded module by runtime name.
modstop <name>Stop a running module.
modunload <name>Unload a stopped module from runtime.
modrun <path.elf>Load and start module in one command.
lsmodList currently loaded modules with state and memory sizes.
modinfo <name>Show runtime module metadata and exported details.
displayList registered display drivers and advertised capabilities.
wifi statusShow Wi-Fi state, SSID, IP, and RSSI when connected.
wifi connect <ssid> [password]Connect device to Wi-Fi network (STA mode).
wifi disconnectDisconnect from the current AP.
wifi scanScan nearby access points and show basic metadata.
pkg syncSynchronize package index from configured repository.
pkg searchList available packages from synced index.
pkg listList locally installed packages.
pkg install <name>Download and install package payload to local storage.
pkg remove <name>Remove installed package artifacts.
pkg repo [url]Show or set package repository base URL.
dmesgDump in-memory kernel log ring buffer.
sleep <seconds>Delay execution.
time <command...>Measure command runtime.
crc32 <file>Compute CRC32 checksum.

Diagnostics commands

CommandDescription
i2cdetectProbe I2C addresses and print scan table.
i2cget <addr> <reg> [len]Read bytes from I2C register.
i2cset <addr> <reg> <value...>Write bytes to I2C register.
devls [-v]List core devices and readiness/mount status.
watchdog <status|feed>Watchdog status or manual feed operation.
loglevel [tag] <level>Set global or per-tag logging verbosity.
gpio read|write|mode ...Basic GPIO diagnostics and control.
syncShow filesystem mount/write status and clean-write guidance.
beep [freq_hz] [duration_ms]Play buzzer tone using LEDC.

Configuration and service commands

CommandDescription
fstabShow parsed filesystem mount entries from /sys/etc/fstab.
config <file>Load and dump an INI config file.
config <file> <section>Dump only one INI section.
config <file> <section.key>Print a single INI value.
service listList registered runtime services and state.
service info <name>Show detailed info for one registered service.
vconsole statusShow virtual console buffer/line-index usage and stdout mode.
vconsole clearClear virtual console ring buffer.
vconsole tail [n]Show last buffered shell lines from virtual console.

Error quick-reference

MessageMeaningAction
Unknown command: ...Command is not registered or has typo.Run help, then retry exact command name.
Cannot open: /pathFile/path does not exist or storage unavailable.Check pwd, ls, and storage state via devls -v, lsblk.
No such directory: ...cd target missing.Create with mkdir or correct path.
rmdir failed: ... (Permission denied)Directory is not empty.Remove files/subfolders first, then run rmdir.
I2C read/write failedDevice not reachable or bus issue.Run i2cdetect, verify address/power/wiring.
Cannot load: ...config could not open the requested file.Check path and filename; prefer absolute path.
SD mount failed: ...Card mount unsuccessful.Reinsert card, verify FAT format and SD pins, retry mount.
WDT feed error: ...Watchdog call failed in current task context.Use watchdog status first and avoid long blocking operations without checks.
