Testing Checklist

Run this to validate the newly added command surface end-to-end.

0) Baseline health

uname
devls -v
lsblk
fstab
vconsole status
df

Pass: shell responds, /sys visible, sd0 status matches card state.

1) New diagnostics commands

CommandExpected
i2cdetectI2C scan table printed; if CardKB connected, address 5f appears.
devlsDevice table with statuses (ready, mounted, etc.).
devls -vSame table + pin/address details.
watchdog statusWDT status/timeout text printed.
watchdog feedWatchdog fed. or safe task-not-subscribed message.
loglevel infoGlobal log level confirmation.
loglevel main debugPer-tag log level confirmation.
syncFilesystem status lines for /sdcard//sys and clean-unmount guidance.

2) File command set smoke test

cd /sdcard
mkdir qa
touch qa/a.txt
write qa/a.txt hello
append qa/a.txt world
cat qa/a.txt
wc qa/a.txt
head -n 1 qa/a.txt
tail -n 1 qa/a.txt
grep hello qa/a.txt
stat qa/a.txt
cp qa/a.txt qa/b.txt
mv qa/b.txt qa/c.txt
find a /sdcard/qa
tree /sdcard/qa
du /sdcard/qa
hexdump qa/a.txt 0 32
test -f qa/a.txt
basename /sdcard/qa/a.txt
dirname /sdcard/qa/a.txt
rm qa/c.txt
rm qa/a.txt
rmdir qa

Pass: no unexpected errors, file contents stay correct, and final cleanup succeeds.

3) Script and timing test

write /sdcard/tmp/qa.scr echo QA start
append /sdcard/tmp/qa.scr free
append /sdcard/tmp/qa.scr devls
append /sdcard/tmp/qa.scr echo QA end
source /sdcard/tmp/qa.scr
time source /sdcard/tmp/qa.scr

Pass: script executes in order and time prints real X.XXX s.

4) Navigation and path normalization test

cd /sdcard/tmp
pwd
cd ..
pwd
cd ./etc/../tmp
pwd

Pass: cd .., ., and mixed relative paths resolve correctly without leaving expected root paths.

5) Config and service command tests

write /sdcard/tmp/test.ini [network]
append /sdcard/tmp/test.ini ssid=mywifi
append /sdcard/tmp/test.ini password=secret
config /sdcard/tmp/test.ini
config /sdcard/tmp/test.ini network
config /sdcard/tmp/test.ini network.ssid
fstab
service list
service info klog
vconsole tail 10
vconsole clear
vconsole status

Pass: config dump/lookup works, service registry returns active services, and vconsole commands report expected buffer state.

6) System and module metadata commands

uptime
ps
free
lscpu
env
dmesg
which demo
lsmod
modinfo demo

Pass: commands return clean output; module commands gracefully report not-found if no module is installed.

7) Error-path sanity checks (important)

cat /sdcard/does-not-exist.txt
cd /sdcard/does-not-exist
i2cget 0x00 0x00 1
loglevel invalid
watchdog badcmd
rmdir /sdcard/tmp

Pass: each command reports a clear error message and shell remains stable.
