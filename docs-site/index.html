micro_arch Documentation

micro_arch is an early-stage, Arch-inspired micro-OS shell environment for ESP32-S3 using ESP-IDF and PlatformIO. It boots to a CLI, mounts storage, initializes system buses, and exposes Linux-style commands for file, system, and hardware diagnostics.

PlatformIO + ESP-IDF ESP32-S3 target Project status: early foundation phase

What currently works

  • Boot pipeline with startup diagnostics and interactive shell
  • SD card mount at /sdcard and internal LittleFS mount at /sys
  • Boot-time mount orchestration from /sys/etc/fstab
  • Boot-time filesystem scaffolding and optional startup script execution
  • PSRAM-backed virtual console with tail/clear/status tooling
  • In-memory service registry with service CLI introspection
  • INI configuration parser via config command
  • Broad command surface for file operations, system info, and hardware probing

Latest changes

  • Display multiplexer service added to mirror virtual console output to multiple display modules.
  • New shell command display lists registered display drivers and their capabilities.
  • New shell command modrun <path.elf> performs load + start in one step.
  • Module loader now blocks duplicate module names and rejects low-PSRAM load attempts.
  • Module SDK exports display registration APIs for loadable OLED/E-ink drivers.

What comes next

  • Service-layer stabilization
  • Module runtime and package workflow
  • Display stack and networking expansion
